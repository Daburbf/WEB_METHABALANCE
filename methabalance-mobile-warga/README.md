# METHABALANCE Mobile (Portal Warga & UMKM Biogas TPAS Manggar)

Aplikasi Web Mobile Resmi untuk Warga (380 Sambungan Rumah / SR) dan Pelaku Usaha Mikro (UMKM) Penerima Manfaat Jaringan Pipa Distribusi Biogas TPAS Manggar, Dinas Lingkungan Hidup (DLH) Kota Balikpapan.

## Fitur Utama
1. **Beranda & Keamanan Kompor**: Status katup pengaman jaringan, meteran digital terukur dengan grafik tren harian bergaya trading, kartu billing iuran pemeliharaan RT (Rp 10.000 / bulan), dan kontrol katup darurat mandiri (*Emergency Shut-Off*).
2. **Telemetri Pipa Sektor**: Pembacaan sensor industri real-time (Tekanan kPa, Kemurnian CH₄ NDIR, O₂, H₂S, Suhu, dan Kurva Tekanan 24 Jam).
3. **Lapor Cepat Geotag**: Pengaduan bau gas atau anomali jaringan pipa dengan koordinat GPS otomatis ke petugas DLH Kota Balikpapan.
4. **Profil Sambungan Rumah**: Identitas pelanggan (Ibu Siti Aminah / Bpk. Sukirman), nomor seri meteran IoT, dan preferensi notifikasi.

## Teknologi
- **Pure Semantic HTML5, CSS3, & Vanilla JavaScript (ES6+)**
- **Zero Heavy Dependencies** (Berjalan instan di peramban dan WebView mobile)
- **Inline SVG Graphics**: Grafik garis tren harian bergaya *trading chart* dengan *area fill gradient* dan lencana titik aktif (*live tracking*).
- **Tipografi**: Plus Jakarta Sans & JetBrains Mono
- **Palet Warna**: Emerald Green (`#059669`, `#10b981`), Deep Forest Green (`#0F3B2F`), dan Putih Bersih.
